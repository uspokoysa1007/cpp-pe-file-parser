# cpp-pe-file-parser

Высокопроизводительный анализатор структуры исполняемых файлов Windows (**PE32 / PE32+**, `.exe`, `.dll`, `.sys`) на C++17.

## Возможности
- Разбор заголовков DOS (`IMAGE_DOS_HEADER`) и NT (`IMAGE_NT_HEADERS32` / `IMAGE_NT_HEADERS64`).
- Отображение архитектуры (x86 / x64 / ARM64), точки входа (`AddressOfEntryPoint`), ImageBase, размера стека и подсистемы.
- Детальный анализ секций (`.text`, `.data`, `.rdata`, `.reloc`): виртуальные адреса, размеры в памяти и на диске, флаги доступа (R/W/X).
- **Расчет энтропии Шеннона** для каждой секции (помогает мгновенно обнаружить упаковщики, UPX, обфускацию и зашифрованные пейлоады).
- Анализ таблицы импорта (Import Directory Table): список зависимых DLL и импортируемых функций.

## Сборка
```bash
g++ -O2 -std=c++17 src/main.cpp -o releases/cpp-pe-file-parser.exe
```

## Использование
```bash
./releases/cpp-pe-file-parser.exe <путь_к_exe_или_dll>
```
Если запустить без аргументов, утилита проанализирует собственный исполняемый файл.
